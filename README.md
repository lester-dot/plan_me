# Цифровой профиль компетенций студента

Рабочий MVP-прототип веб-платформы по ТЗ для пилота на специальности `38.02.08 Торговое дело`.

## Запуск

```bash
python3 -m http.server 8080
```

Открыть: `http://127.0.0.1:8080/`

## Тестовые роли

- Студент: `student@demo.ru`
- Преподаватель: `teacher@demo.ru`
- Заведующий: `head@demo.ru`
- Методист: `method@demo.ru`
- Директор: `director@demo.ru`
- Работодатель: `employer@demo.ru`
- Администратор: `admin@demo.ru`

Пароли в прототипе не требуются: роль выбирается в левом меню. Это демонстрационный RBAC-слой для проверки сценариев MVP.

## Что реализовано

- Кабинет студента с готовностью, таймлайном достижений и переключением публичного портфолио.
- Карта компетенций с моделью ЗУНК: знания, умения, навыки, индикаторы и связи с дисциплинами.
- Образовательный процесс пилотной специальности: дисциплины, профессиональные модули, учебная и производственная практика.
- Единая сущность Evidence: оценки, практические работы, проекты, практики, конкурсы.
- Расчет компетенций по весам дисциплин, типам доказательств и статусам верификации.
- Очередь верификации для преподавателя, заведующего и методиста.
- Базовая аналитика по группе и специальности.
- Кабинет работодателя: профиль организации, модерация, запросы по компетенциям, подбор студентов по `match_score`.
- Приглашения на практику/стажировку и отзывы работодателя как источник внешней верификации.
- Расширенная аналитика: спрос работодателей, дефициты компетенций, управленческие KPI.
- Методическая аналитика: матрица дисциплин/практик и компетенций, пустые зоны, дублирование.
- Отчеты и экспорт CSV по портфолио, методическому покрытию и запросам работодателей.
- CSV-импорт оценок в формате `student_email,discipline_code,score,title`.
- Экспорт текущего профиля через печать в PDF.
- UX-обратная связь: тосты об успехе/ошибке для действий (добавление доказательства, верификация, импорт CSV, экспорт, приглашения, отзывы, портфолио).
- Валидация форм: балл 0–100 и название события, обязательные и корректные компетенции в запросе работодателя, отчёт об импортированных/пропущенных строках CSV.
- Пустые состояния для списков (доказательства, очередь верификации, подбор, приглашения, поиск по компетенциям).
- Подтверждение перед сбросом демо и подсветка выбранной компетенции (клик/клавиатура, `aria-pressed`).

Данные хранятся в `localStorage`, поэтому изменения сохраняются в браузере до нажатия `Сбросить демо`.

## Дизайн-система

Визуальная система оформлена как современный технологичный edtech-дашборд с референсом на Skillbox и Нетологию, но без копирования логотипов и брендов: тёмная левая навигация-рельс, светлая рабочая область, градиентный hero-блок, мягкие тени и скруглённые карточки.

- Фон: мягкий градиент `#eef0f8` с подсветкой углов — спокойный, но «продуктовый».
- Поверхности: белые карточки `#ffffff` с тонким контуром `#e8eaf4` и многослойными мягкими тенями (без «плоского» жёсткого чёрного контура).
- Главный action: фиолетовый `#6c47ff` с градиентами (`#7d5cff → #6c47ff → #4a29c4`) — кнопки, активная навигация, кольца прогресса.
- Навигация: тёмный рельс `#1b1c3a → #12132a` со светлым текстом, активный пункт — фиолетовый градиент с тенью.
- Акценты KPI и графиков: бирюзовый `#14b8d4`, зелёный `#22c55e`, янтарный `#ffb020`, розовый `#ff4d8d`.
- Статусы: мягкие пилюли — успех (зелёный), на проверке (фиолетовый), доработка (янтарный), отклонено (красный), нейтральные (серый).

Интерфейс остаётся прикладным: первый экран сразу ведёт в кабинет, аналитику и карту компетенций, но визуально воспринимается как продвинутая образовательная платформа.

Основные приёмы дашборда: тёмный sticky-рельс навигации, стеклянный sticky-topbar, градиентный hero с кольцом готовности, KPI-плитки с цветными акцентами и крупными табличными цифрами, градиентные progressbar-графики, hover-lift микровзаимодействия, карточное поведение таблиц на мобильном, явные focus-состояния (кольцо фокуса), touch-targets от 44px, поддержка `prefers-reduced-motion` и корректная печать в PDF.
